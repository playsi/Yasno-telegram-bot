# Yasno Telegram Bot

Telegram-бот, який надсилає графік планових відключень світла від [Yasno](https://yasno.ua)
і повідомляє, коли графік змінюють. Працює **повністю на GitHub**: без сервера, без хостингу,
без бази даних. Раз на годину GitHub Actions запускає бота, а дані зберігаються
в репозиторії в зашифрованому вигляді.

## Що вміє

- **Одне актуальне повідомлення з графіком** на сьогодні й завтра. Бот щогодини редагує його
  (без звуку), щоб там було видно:
  - коли наступне відключення і **через скільки** воно почнеться;
  - **скільки триватиме** відключення, або коли увімкнуть світло, якщо його зараз немає;
  - скільки годин без світла за добу.
- **Сповіщення лише про справжні зміни**: «📅 З'явився графік на завтра» або «🔔 Змінено графік».
  Опівночі «завтра» стає «сьогодні», але це не вважається зміною, тож сповіщення не буде.
- **Тихі години**: з 23:00 до 7:00 сповіщення приходять без звуку (налаштовується).
- **Статистика** (`/stats`): години без світла за 7 і 30 днів, кількість відключень,
  найдовше відключення, кількість змін графіка, а також коли вимикали й вмикали світло
  в кожен з останніх днів.
- **Історія змін графіка** (`/history`): усі версії графіка за останні дні й час, коли їх
  опублікували.
- **Надійність**:
  - повторне натискання `/start` не дає дублів графіка;
  - бот не пропускає повідомлення, навіть якщо Telegram скинув нумерацію оновлень;
  - коли Yasno не відповідає, бот показує останній відомий графік і не пише «Дані недоступні»;
  - користувачів, які заблокували бота, бот видаляє з розсилки;
  - коли Telegram обмежує частоту запитів (помилка 429), бот чекає й повторює запит.

### Команди

| Команда | Що робить |
|---|---|
| `/start` | підписатися й отримати свіжий графік (старе повідомлення з графіком видаляється) |
| `/stats` | статистика відключень |
| `/history` | історія змін графіка |
| `/stop` | відписатися |
| `/help` | довідка |

> Бот запускається приблизно раз на годину, тому відповідь на команду може прийти із затримкою.
> GitHub не гарантує точного часу запуску за розкладом.

## Налаштування за 10 хвилин

### 1. Створіть бота

Напишіть [@BotFather](https://t.me/BotFather) команду `/newbot` і збережіть токен
(вигляду `123456789:AA...`).

Команди можна додати в меню бота: `/setcommands` у BotFather, а потім:

```
start - Підписатися й отримати графік
stats - Статистика відключень
history - Історія змін графіка
stop - Відписатися
```

### 2. Зробіть fork репозиторію

Натисніть **Fork** угорі сторінки. У форку відкрийте вкладку **Actions** і натисніть
**I understand my workflows, go ahead and enable them**: у форках запуск за розкладом
за замовчуванням вимкнено.

### 3. Знайдіть свій регіон, оператора і групу

| Локація | `REGION` | `DSOS` | Оператор (ОСР) |
|---|---|---|---|
| Київ | `25` | `902` | ПРАТ «ДТЕК Київські електромережі» |
| Дніпро та Дніпропетровська область | `3` | `301` | ДнЕМ («ДТЕК Дніпровські електромережі») |
| Дніпро та Дніпропетровська область | `3` | `303` | ЦЕК (Центральна енергетична компанія) |

Yasno працює лише в Києві та на Дніпропетровщині. Для інших областей бот не підійде.

**Група** (`GROUP`) має вигляд `1.1`, `3.2` тощо. Знайти свою групу можна так:

- на сайті [yasno.ua](https://yasno.ua): введіть адресу в розділі графіків відключень;
- або покажіть усі групи вашого оператора командою `--list-groups` (див. «Локальний запуск»):
  ```bash
  REGION=25 DSOS=902 python main.py --list-groups
  ```

Перевірити, як виглядатиме графік, можна без Telegram:

```bash
REGION=25 DSOS=902 GROUP=3.1 python main.py --preview
```

### 4. Додайте секрети

У форку: **Settings → Secrets and variables → Actions → New repository secret**.

| Secret | Обов'язковий | Опис |
|---|---|---|
| `BOT_TOKEN` | так | токен від BotFather |
| `REGION` | так | ID регіону з таблиці вище |
| `DSOS` | так | ID оператора з таблиці вище |
| `GROUP` | так | ваша група, наприклад `3.1` |
| `ENCRYPTION_KEY` | так | будь-який довгий випадковий рядок, ним шифруються дані |
| `PAT_TOKEN` | ні | Personal Access Token з правом `contents: write`; якщо його немає, використовується стандартний `GITHUB_TOKEN` |

Згенерувати `ENCRYPTION_KEY`:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

> ⚠️ **Не змінюйте й не губіть `ENCRYPTION_KEY`.** Без нього збережені дані не розшифрувати.
> Якщо ключ не підходить, бот зупиниться з помилкою: він не стиратиме базу й не почне
> з порожньої.

Необов'язкові налаштування задаються на вкладці **Variables** (поруч із Secrets):

| Variable | За замовчуванням | Опис |
|---|---|---|
| `QUIET_HOURS` | `23-7` | години, коли сповіщення приходять без звуку; `off`, щоб вимкнути |

### 5. Запустіть

**Actions → Yasno Telegram Bot → Run workflow**. Після цього напишіть боту `/start`
і запустіть workflow ще раз (або дочекайтеся наступного запуску за розкладом).

## Як це працює

```
GitHub Actions (cron "17 * * * *")
   │
   ├─ 1. Yasno API → графік вашої групи на сьогодні й завтра
   ├─ 2. Telegram getUpdates → нові команди (/start, /stats, ...)
   ├─ 3. редагує повідомлення з графіком у кожного користувача,
   │     сповіщає лише тих, у кого графік справді змінився
   └─ 4. git commit зашифрованих даних (лише якщо вони змінилися)
```

Дані в репозиторії (зашифровано Fernet, ключ `ENCRYPTION_KEY`):

| Файл | Що всередині |
|---|---|
| `bot_data.json` | користувачі, ID їхніх повідомлень, останній побачений графік, оброблені `update_id` |
| `data/history/YYYY-MM.enc` | усі версії графіка на кожну дату за місяць: з них рахується статистика |

Історія лежить у помісячних файлах, щоб щогодинні коміти змінювали лише невеликий файл
поточного місяця, а розмір репозиторію не ріс надто швидко.

Раз на добу бот робить коміт, навіть якщо нічого не змінилося: GitHub вимикає розклад
у репозиторіях без активності протягом 60 днів (наприклад, влітку, коли відключень немає).

## Локальний запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp secrets.env.example secrets.env   # заповніть значення
python main.py                       # один запуск, як у GitHub Actions
python main.py --preview             # лише показати графік у консолі
python -m pytest -q                  # тести
```

> Не запускайте бота локально з тим самим токеном одночасно з GitHub Actions.
> Обидва запуски отримуватимуть ті самі команди.

## Структура коду

```
main.py                 точка входу
yasno_bot/
  cli.py                аргументи командного рядка, один запуск бота
  config.py             змінні оточення
  yasno.py              клієнт і парсер Yasno API
  schedule.py           модель графіка, розрахунок відключень і тривалостей
  history.py            архів версій графіка і статистика
  formatting.py         тексти повідомлень
  telegram.py           клієнт Telegram (ретраї без дублів, 429, блокування)
  storage.py            зашифроване JSON-сховище
  bot.py                логіка: команди, розсилка, виявлення змін
tests/                  pytest
```

## Обмеження

- Бот перевіряє графік раз на годину, а GitHub може запустити workflow із запізненням.
- Telegram зберігає непрочитані повідомлення 24 години. Якщо workflow не запускався довше
  (наприклад, його вимкнули), команди за цей час буде втрачено.
- Telegram дозволяє ботам видаляти лише повідомлення, молодші за 48 годин, тому старі
  сповіщення можуть лишитися в чаті.
- Статистика рахується за опублікованим графіком, а не за фактичною наявністю світла.
- Yasno не публікує документацію API. Якщо формат відповіді зміниться, бот запише помилку
  в лог workflow і показуватиме останній відомий графік.

## Оновлення зі старої версії

Нічого робити не потрібно. Бот автоматично перетворить старий `bot_data.json` у новий формат,
збереже всіх користувачів і не надішле зайвих сповіщень. Статистика почне збиратися
з першого запуску нової версії.
